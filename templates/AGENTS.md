# Repository instructions

Before modifying the repository:

1. Read `docs/manifest.json`.
2. Apply the installed rules relevant to the requested work.
3. Apply the installed guides relevant to every affected technology.
4. Use the entries with `type: "operation"` in `context` as the authoritative repository-specific reference.

Repository tooling and CI take precedence for rules they mechanically enforce.

Do not broaden the requested scope or modify unrelated code.
